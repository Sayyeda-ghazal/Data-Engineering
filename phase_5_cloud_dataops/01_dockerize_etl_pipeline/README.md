# #01 Dockerize an ETL Pipeline

**Difficulty:** Intermediate

## Problem

Package your Phase 2 Airflow pipeline in Docker Compose (Airflow + Postgres + your custom operator). Make it runnable with a single docker-compose up command.

## Hints

- Use official `apache/airflow` image
- Mount DAGs folder as a volume

## Technologies

Docker, Docker Compose, Airflow
