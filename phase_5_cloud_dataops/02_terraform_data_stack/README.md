# #02 Terraform a Data Stack

**Difficulty:** Advanced

## Problem

Write Terraform code to provision: an S3 bucket with versioning, a Redshift cluster, an IAM role for Glue, and a Glue crawler. Use modules and variables.

## Hints

- `aws_s3_bucket`, `aws_redshift_cluster` resources
- Use `terraform.tfvars` for secrets

## Technologies

Terraform, AWS (S3, Redshift, Glue, IAM)
