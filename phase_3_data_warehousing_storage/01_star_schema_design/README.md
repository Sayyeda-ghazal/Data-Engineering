# #01 Design a Star Schema

**Difficulty:** Intermediate

## Problem

For a retail company with orders, products, customers, and stores, design a star schema. Create fact_sales, dim_customer, dim_product, dim_date, dim_store. Justify your grain choice.

## Hints

- Grain = one row per order line item
- Date dimension should be pre-built

## Technologies

SQL, Dimensional Modeling
