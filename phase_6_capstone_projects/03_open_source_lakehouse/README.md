# #03 Open Source Lakehouse

**Difficulty:** Expert

## Problem

Build a complete Lakehouse: MinIO (local S3) + Apache Iceberg + Trino + dbt + Apache Superset. Automate with Airflow. Handle schema evolution and time travel queries.

## Hints

- Use `docker-compose` to orchestrate all services
- Iceberg `MERGE INTO` for CDC patterns

## Technologies

MinIO, Apache Iceberg, Trino, dbt, Apache Superset, Airflow
