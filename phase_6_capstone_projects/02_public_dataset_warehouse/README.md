# #02 Public Dataset Warehouse

**Difficulty:** Advanced

## Problem

Pick a large public dataset (NYC Taxi, GitHub Archive, or Stack Overflow). Design a full DWH with star schema in BigQuery/Snowflake, dbt models, data quality tests, and an analytics layer.

## Hints

- Ingest with Airbyte or custom scripts
- Expose Gold layer via Looker Studio or Metabase

## Technologies

BigQuery/Snowflake, dbt, Airbyte, Looker Studio/Metabase
